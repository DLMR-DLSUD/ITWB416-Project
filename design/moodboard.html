CICS/MOOD

Silver first. The page is built like a piece of hardware: brushed-metal stripes, keyboard keys, ID badges and a terminal screen. Instead of the usual hero, cards and buttons, every part of the site borrows from the objects IT and CS students actually use. Anything metal (keys, bars, badges, medals, big lettering) uses one shared set of silver gradients. Everything else stays flat.

06 · Illustrator notes

How each signature piece is built

  • Silver gradient (main): linear, top to bottom: #FFFFFF 0%, #E3E6EA 35%, #B7BDC4 55%, #DDE0E4 75%, #9AA1A9 100%. Chrome bar, medals, chips.
  • Soft silver: #FFFFFF, #EEF0F2 60%, #D6DADF 100%. Panels, badges, key tops. Dark metal: #4A5057, #2C3035 50%, #111214 100%. Rail, badge headers, dark keys.
  • Silver text: #5E656D, #A3AAB2 30%, #3A3F45 52%, #7C848D 72%, #2C3035 100%. Darker "gunmetal" silver so it never fades into the light background. Fill for the second half of mega words (Type > Create Outlines, then apply the gradient).
  • Chrome bar: 24px rectangle with the main silver gradient, 1px white line on top, 1px Gunmetal line on the bottom.
  • Keycap: Steel-to-Gunmetal gradient rectangle (base), then a soft-silver rectangle inset 4px on the top and sides and 12px at the bottom. Dark keys use Black + dark metal. Small label top-left in mono 9px.
  • Mega type: Space Grotesk Bold, tight tracking (-4%). Split a word: first half solid black, second half silver text gradient. No outline fonts.
  • Access badge: black header strip with a Chrome 2 slot, program code in solid mono, silver 4-square chip, barcode of 1–4px black bars, footer row.
  • Terminal: Black body, Graphite title bar with 3 Steel squares, mono text, Chrome 3 tags, blinking block cursor.
  • Hex medal: Gunmetal/Steel/Gunmetal hexagon with a hexagon 6px smaller in the main silver gradient on top. Dark variant: Black + dark metal.
  • Side rail: 56px black bar, college name rotated 90°, page numbers 01–06.
  • Green rule: DLSU-D green only marks "active / on": current page, Enter key light, deadline tag.
  • Gradients only for metal (the 4 above). No shadows, blur or transparency. Strokes 1px.
  • Layout: 1200px width, 24px gutters, 80px between sections.
