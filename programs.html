PROGRAMS

The BS Information Technology and BS Computer Science programs of CICS: what you'll study, the tracks you can take and where they can lead.

01

Undergraduate Programs

>>>

CICS offers two bachelor's programs, each run by its own department and accredited Level III (valid until 2030). The college plans to add more programs in the future.

ACCESS · UNDERGRAD
IT

BS Information Technology

Information Technology Department · Level III

ID · BSIT-01BSIT

Program description

BSIT gives students comprehensive, hands-on training in current IT concepts and applications, from programming and databases to networks and security.

Students choose a track in Network Technology or Software Technology, with elective domains in Web Design & Applications Development and Game Development, and finish with a capstone project.

Curriculum overview

CORE 01BUILD
  • Programming
  • Databases
CORE 02CONNECT
  • Networking
  • Systems Integration
CORE 03SECURE
  • Information Assurance & Security
  • System Administration
CORE 04SHIP
  • Track Electives
  • Capstone Project

Core areas of the program. See the prospectus for the full course list per year.

Career paths

  • Database Administrator
  • Network & Systems Administrator
  • Information Security
  • Web Developer
  • Programmer
  • Technical Support
  • IT Entrepreneur
  • IT Instructor / Trainer
  • Researcher
ACCESS · UNDERGRAD
CS

BS Computer Science

Computer Science Department · Level III

ID · BSCS-02BSCS

Program description

BSCS focuses on computing theory and its applications, building abstract reasoning, analytical thinking and research skills.

Students choose a track in Robotics or Mobile and Game Development, with specialization electives in Intelligent Systems and Game Development. Graduates are ready for computing careers and graduate study.

Curriculum overview

CORE 01CODE
  • Programming
  • Data Structures
CORE 02THINK
  • Algorithms
  • Computer Systems
CORE 03ENGINEER
  • Software Engineering
  • Research
CORE 04SPECIALIZE
  • Intelligent Systems
  • Game Development

Core areas of the program. See the prospectus for the full course list per year.

Career paths

  • Application Developer
  • Database Programmer & Designer
  • Mobile & Game Developer
  • Systems Analyst
  • Researcher
  • Teacher / Trainer
02

Who Can Apply

>>>

Both programs accept three kinds of applicants. CICS does not currently list graduate programs.

[A1]FRESHMEN

First-year students

Senior High School completers, equivalent secondary completers from abroad, and ALS passers certified for college.

[A2]TRANSFEREES

Transferring students

Students who completed no more than 75% of a curriculum at another CHED-recognized or foreign college.

[A3]SECOND COURSE

Degree holders

Graduates of any college degree from a CHED-recognized or foreign institution.

03

Specializations & Tracks

>>>

Each program has two tracks, plus elective domains you can focus on in your upper years.

[T1]BSIT · TRACK

Network Technology

Networks, infrastructure and system administration.

[T2]BSIT · TRACK

Software Technology

Building and integrating software and web applications.

[T3]BSIT · ELECTIVES

Web Design & Applications Development

Designing and developing web-based applications.

[T4]BSCS · TRACK

Robotics

Computing applied to intelligent physical systems.

[T5]BSCS · TRACK

Mobile & Game Development

Mobile apps and game development.

[T6]BSCS · ELECTIVES

Intelligent Systems

AI-focused specialization electives.
